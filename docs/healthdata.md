This paper was developed for a course in health data analytics during my bachelor's degree at UNB Saint John. It was co-created with two health students (cited in the file), who provided the health literature context while I handled the coding in R. Development of the research question, writing of the report, and performing the data analysis was all done collaboratively. Generative AI was used in debugging the code. Sections of the code were adapted from samples provided in the course lessons. Survey data used in this analysis came from the Behavioral Risk Factor Surveillance System, more information on the dataset is included in the analysis. The html file was created using Quarto.
